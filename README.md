# nessakm.github.io
GitHub Pages site for nessakm

## Viewing changes locally before publishing

You can locally run the site by running the following command from the terminal at the root of this project:
```shell
bundle exec jekyll serve --livereload
```

You should see the command output something like this:
```shell
...
LiveReload address: http://127.0.0.1:35729
    Server address: http://127.0.0.1:4000/
  Server running... press ctrl-c to stop.
        LiveReload: Browser connected
```

Copy the 'Server address' in your browser to view your site. Ex:
```shell
http://127.0.0.1:4000/
```

When you are done, hit 'Ctrl+C' in the terminal to stop the server.
